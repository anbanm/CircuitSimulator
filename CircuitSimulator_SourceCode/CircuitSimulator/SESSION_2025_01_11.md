### 3. Implemented Terminal Polarity-Based Direction Logic 🔧
**File**: `CircuitWire.cs` (lines 483-523)
**Logic**:
```csharp
// Current flows from OUTPUT terminal → INPUT terminal
bool startIsOutput = !startTerminal.isInput;
bool endIsInput = endTerminal.isInput;

if (startIsOutput && endIsInput)
    // Forward: Animation flows start→end
else if (!startIsOutput && !endIsInput)
    wireCurrent = -wireCurrent; // Reverse: Animation flows end→start
```

**Terminal Definitions**:
- Battery Red (+): OUTPUT terminal (isInput = false)
- Battery Green (-): INPUT terminal (isInput = true)
- Bulb/Resistor: Both INPUT and OUTPUT terminals
